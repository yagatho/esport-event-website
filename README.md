# Strona internetowa zapisy do eventu esportowego "Łódzkie Grające – Regionalne Mistrzostwa Esportowe"
Autorzy: Szymon Grucela, Wiktor Rzepka

### Opis eventu
"Łódzkie Grające” to pierwsze oficjalne Mistrzostwa Esportowe Województwa Łódzkiego, mające na celu wyłonienie najlepszych graczy i zespołów w regionie. Turniej skupia pasjonatów e-sportu, promuje zdrową rywalizację oraz integruje lokalną społeczność gamingową.
